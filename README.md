# 🏀 Scoreboard

A simple and interactive **Scoreboard Web Application** built using **HTML, CSS, and JavaScript**.

This project was created as a practice project to improve my JavaScript fundamentals, DOM manipulation, event handling, and basic web application development.

## 🚀 Features

- ➕ Add points to Team/Player 1
- ➕ Add points to Team/Player 2
- 🔢 Multiple point increments
- 🔄 Reset the scoreboard
- 🎨 Clean and simple scoreboard interface
- ⚡ Instant score updates using JavaScript
- 📱 Responsive design

## 🛠️ Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling and layout
- **JavaScript** – Score calculation and DOM manipulation

## 🎮 How It Works

The scoreboard uses JavaScript to keep track of the scores.

When a user clicks a scoring button:

1. JavaScript receives the button click.
2. The corresponding score is updated.
3. The updated score is displayed on the webpage immediately.
